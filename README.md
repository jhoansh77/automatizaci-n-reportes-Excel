# automatizaci-n-reportes-Excel
# Automatización básica de reportes en Excel

Este proyecto automatiza la limpieza y generación de reportes a partir de archivos Excel,
pensado para pequeños negocios que realizan sus reportes de forma manual.

## ¿Qué problema resuelve?
Reduce el tiempo y los errores en la elaboración de reportes periódicos.

## Tecnologías
- Python
- Pandas
- Excel
